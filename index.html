Projects

  • 2026

    Sea Battle

    A turn-based 1v1 naval game you can play online or against a bot. Each of the five ships has an ability, like an airstrike, radar or torpedo, and using one replaces your shot for that turn. Two browsers connect directly over WebRTC, with a small Node server only introducing them. Both players commit to their fleet before play, and every report is replayed at the end so cheating gets flagged. The bot keeps a heat map of where the remaining ships could be and sinks a fleet in about 21 turns; random shooting takes about 96. The ships, water effects and sound are all generated in code.

    TypeScript, Three.js, WebRTC, Web Audio, Nodesource
  • 2023

    Spring Arm

    A third-person camera for Three.js that works like a spring arm in a game engine. It raycasts between the target and the camera, pulls in when something blocks the view, and eases back out when the path clears, so the camera never clips through the scene.

    JavaScript, Three.jssource
  • 2023

    Ray Tracing

    A CPU ray tracer with a live editor. Rays bounce up to five times, each material's roughness scatters its reflections, and frames accumulate so the image cleans up over time. Rendering runs in parallel, and you can add spheres and change their materials while it draws.

    C++, GLM, Dear ImGui, Walnut
  • 2023

    Pixel Art

    A small pixel painting tool. You paint on a grid with the mouse, choose colours from a picker, and clear the canvas with one key. The grid and its drawing are written by hand on top of SFML.

    C++, SFML, Dear ImGui
  • 2023

    Space Invaders

    An Asteroids-style shooter written from scratch. You fly a ship with thrust, rotation and drag, and shoot obstacles for score. Collisions use the separating axis theorem so rotated sprites collide accurately, and an in-game panel tunes ship speed, rotation and drag while you play.

    C++, SFML, Dear ImGui

    An Unreal Engine plugin for online sessions. It wraps the Online Subsystem, with Steam as the backend, so a game can create, find, join, start and destroy sessions. It includes a menu you can set up from Blueprints with a player count and match type.

    Unreal Engine, C++, Steam
